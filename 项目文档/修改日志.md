### 四、本次引入的已知限制

> 代码已回退，下列限制随之消失；保留作为重新实现时的检查项。

| 限制 | 说明 | 何时解决 |
|---|---|---|
| 没有任务 | `App_Init()` 为空，`vTaskStartScheduler()` 未调用，主循环停在 `main.c` 的 `while(1)` | 任务层落地时 |
| CAN 帧无人消费 | `Board_PollCan()` 已实现但无人调用，帧会堆在环形缓冲（32 帧）直到丢弃 | 底盘任务落地时 |
| 轮径为 0 | `BOARD_WHEEL_DIAMETER_MM = 0.0f`，`SetSpeed()` 拒绝运动 | H-4 确认后 |
| 协议未验证 | CAN 帧映射、校验方式、速度上限均待实物确认 | P-1 / P-2 / P-3 |
| 中断未实测 | CAN RX 中断只在代码层接通，未上台架 | 硬件到位后 |
| 堆未调整 | 仍是 8 KB，三任务会不够 | S-1 确认后 |
