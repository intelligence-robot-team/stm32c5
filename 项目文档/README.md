# 项目文档索引

STM32C593RGT6 底盘 + 机械臂控制工程。本目录是方案与决策的唯一来源，根目录 `初步方案.md` 已拆分为下列文档。

## 文档职责

| 文档 | 内容 | 什么时候改 |
|---|---|---|
| [代码架构.md](代码架构.md) | 分层、目录、对象模型、数据结构、启动流程、Platform 取舍、与 skill.md 的偏离 | 分层或接口变化时 |
| [外设及硬件映射.md](外设及硬件映射.md) | CubeMX 已配外设、板级映射表、占位项、资源冲突、重生成注意事项 | 原理图到位、改 .ioc2 时 |
| [电机协议_ZDT_X.md](电机协议_ZDT_X.md) | 张大头 X 固件帧格式、应答格式、CAN 映射推导、单位换算 | 协议核对或换驱动器时 |
| [待确认问题.md](待确认问题.md) | 未定项，按 P/H/S 编号，含影响面与当前处理方式 | 每次确认或推翻一条时 |
| [修改日志.md](修改日志.md) | 每次变更的文件、原因、影响 | 每次改代码或改文档时 |

## 状态标记

| 标记 | 含义 |
|---|---|
| `[已实现]` | 代码已存在且编译通过 |
| `[骨架]` | 代码存在，但协议或参数未经实物验证 |
| `[待实现]` | 只有设计，没有代码 |
| `[待确认]` | 缺少信息，不能擅自假设 |

## 当前基线（2026-11-27）

- **工程里没有用户代码**：只有 CubeMX 生成脚手架，`main.c` 仍是 `mx_system_init()` + 空 `while(1)`。
- 构建：`cmake --build --preset debug_GCC_STM32C593RGT6` 通过，`text 18408 B / data 96 B / bss 2816 B`。
- 本目录的架构、对象模型、协议解析均为**设计**，尚未实现；确认硬件与协议后按 [代码架构.md](代码架构.md) 第 12 节实施。
- 目前唯一的非文档改动是根目录 `.gitignore`（按提交策略重写，不涉及代码）。

## 维护约定

1. 改代码必须同时改 [修改日志.md](修改日志.md)，写明文件与原因。
2. 任何新增的"不知道"，先写进 [待确认问题.md](待确认问题.md) 再写代码，不允许在代码里用魔法数字代替。
3. 只有 `bsp/board_init.c` 与 `bsp/board_config.h` 允许出现"哪个轮子挂哪个地址"这类板级信息。
4. `generated/` 下的文件都会被 CubeMX 覆盖，改动必须在 [外设及硬件映射.md](外设及硬件映射.md) 的"重生成检查清单"里登记。
